Setup and troubleshooting

First connection

  1. Connect the iPhone or iPad to the same network as the Modbus TCP device.
  2. Allow Local Network access when prompted by iOS.
  3. Create a profile by choosing the device, then enter its address. Port and Unit ID are prefilled and remain editable.
  4. Select Connect. Valid profiles are stored only on the device.

Common settings

The default Modbus TCP port is 502 and the default Unit ID is 1. Your device may use different values; consult its manufacturer documentation.

Supported devices

  • ALFA by Sinapsi: grid power and energy, production, and current tariff band.
  • Shelly Pro 3EM: three-phase net power and imported and returned energy.
  • Shelly Pro EM: first single-phase channel; the Modbus TCP server must be enabled in Shelly settings.
  • SunSpec Modbus: detection of inverter models 101–103 and meter models 201–204 at standard base addresses 40000, 0, or 50000.

The dashboard displays only the measurements actually exposed by the selected profile.

If the device does not respond

  • Make sure Local Network permission is enabled in iOS Settings.
  • Check that Wi-Fi or VPN can reach the device subnet.
  • Check the IP address entered in the profile.
  • Make sure a router or firewall is not blocking the Modbus TCP port.

Demo mode

The demo uses simulated data only and makes no Modbus connections. A DEMO label remains visible on the dashboard.

Concurrent access

Modbus Energy opens short read-only connections. It can usually operate alongside other clients, but simultaneous connection limits depend on the device.

Trademarks and compatibility

Manufacturer and product names are used solely to identify compatible profiles. Modbus Energy is an independent app and is not affiliated with or endorsed by the manufacturers listed.
